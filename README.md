# rideleanway.com

Leanway'in web sitesi: ana sayfa ve gizlilik politikası. GitHub Pages ile yayınlanır.

- `index.html` — ana sayfa
- `gizlilik/` — gizlilik politikası (Türkçe + İngilizce); `privacy/` İngilizce bölüme yönlendirir
- `CNAME` — özel alan adı (rideleanway.com)

Uygulamanın kodu ayrı, gizli depoda: `yesilhalil55/leanway`.
Gizlilik politikası değişirse uygulamanın gerçekte topladığı verilerle uyumlu tutulmalı.
